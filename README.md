# 🍕 Feroz Wattwaan Pizza Shop - POS System
**Real Business Solution | Python Tkinter Project**

A complete Point of Sale & Udhar Management system built for a local pizza shop in Feroz Wattwaan, Pakistan.

### ✨ Key Features
- **Smart Billing:** Customer name, pizza type, qty, auto-bill (e.g. Bill_Ali.txt)
- **Udhar Management:** Full Paid / Half Payment / Full Udhar - Auto saves to udhar_list.txt
- **Daily Sales Report:** Total Sale button for daily revenue
- **Offline & Fast:** Works without internet

### 🛠️ Tech Stack
- Python 3, Tkinter, File Handling, PyInstaller

### 🚀 How to Run
python final_shop.py
